# SO-101 実機編の観測記録

2026-10-21、著者のSO-101実験環境で取得した写真とAPIの記録。
公開データセットの抜粋ではない。写真は実際のカメラ画像で、生成画像は使っていない。
ロボットの制御コードはこの資料にも本の実機編にも転載しない。

`observations.json`に、段取りを固定した把持5回の枠・姿勢・追跡履歴と、
保持中5枚・空の爪5枚の両モデルの回答を保存した。
`provenance.json`は元の制御コードの版と較正ハッシュ。
画像ファイルとSHA256は各caseにあり、入力ファイル全体の一覧は`checksums.json`。
`report.json`は保存記録から計算した値で、数値の解釈はfindingsのF-042に記載した。

再集計は `python3 scripts/report-so101.py`。
このスクリプトはAPIを呼ばず、カメラやアームにも接続しない。
写真を含む資料を取得すれば、ロボットを所有していなくても数値を確認できる。

写真の判定ラベルはCodexの目視確認。モデルの回答を隠した確認ではなく、
独立した人間の正解ラベルではない。同じ物と場所の繰り返しで、一般的な精度ではない。

`exploratory.json`には、運搬の失敗と、動作を呼ばず保持中と答えた準備段階の例を別に保存。
把持5回の集計に混ぜていない。findingsのF-043を参照。

図は `uv run --with matplotlib --with pillow python scripts/render-so101-figures.py <出力先>` で描画する。
把持の写真は固定した反復の1回目を使う。全フレームを配置し、対象の描き直しはしない。
日本語フォントにはmacOSのヒラギノ角ゴシックかNoto Sans CJK JPを使う。
