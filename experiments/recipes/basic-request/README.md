# 第1章：最初のリクエストと試用予算の記録

実行するコードは[examples/first.ts](../../../examples/first.ts)です。
書籍の掲載コードと同じ問い合わせ・質問を使います。

- `usage-2026-10-23.json`：SDK 0.6.0、Jev 1.13.0で1回実行した記録。質問・回答・usageを含む
- `ambiguous-2026-11-03.json`：同じ3択に、配送と紛失のどちらとも読める問い合わせを送った記録。確率が分かれ、確信度が下がる例として第1章に載せている。同じ文でも実行ごとに値が少し変わる（この日の別の実行では0.65・0.35・0.48）
- `recipe-budget-2026-10-23.json`：保存済みの文章・画像の結果から、入力トークンと概算費用を集計した根拠

この記録にはAPIキーを含めていません。
金額は、記録した入力トークン数と当時の単価からの換算です。
請求明細や残高を確認した実支払額ではありません。

予算の記録には、集計したファイルのパス・SHA-256・件数と、対象外にした処理を残しています。
文字列の分類や画像の評価を再実行する場合の概算で、別のモデルや実機操作の費用は含めていません。
測定当時の事実は、[findings.mdのF-044](../../findings.md#f-044-書籍の初回サンプルは431入力トークン文章画像の単価換算は概算約174ドル)にあります。

`usage-2026-10-23.json`の`code_sha256`は、採取時のファイルを指すハッシュです。
現在の`examples/first.ts`のファイル全体とは一致しません。
同じ記録に保存した`request_code`は、現在の例がAPIへ渡すコードと一致しています。
